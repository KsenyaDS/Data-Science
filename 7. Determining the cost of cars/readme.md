# Определение стоимости автомобилей

ML-проект по построению модели, которая предсказывает рыночную стоимость подержанного автомобиля по его техническим характеристикам и комплектации.

## 📋 Описание проекта

Сервис по продаже автомобилей с пробегом **«Не бит, не крашен»** разрабатывает приложение, чтобы привлечь новых клиентов. В нём пользователь может узнать рыночную стоимость своего автомобиля. Для этого нужна модель машинного обучения, которая по характеристикам авто (марка, год, пробег, мощность и т. д.) предсказывает цену.

### 🎯 Критерии заказчика

При выборе модели важно учитывать три показателя:
1. **Качество предсказания** — метрика RMSE, целевое значение < 2500.
2. **Время обучения модели** — чем меньше, тем лучше.
3. **Время предсказания** — критично для отклика в мобильном приложении.

## 📊 Данные

Файл: `/datasets/autos.csv`

## 📐 Метрика качества

**RMSE (Root Mean Squared Error)** — корень из среднеквадратичной ошибки.

Требование заказчика: **RMSE < 2500**.

## 🚀 Этапы работы

1. **Загрузка данных** из файла `/datasets/autos.csv`.
2. **Изучение данных (EDA)**:
   - анализ распределений,
   - поиск пропусков,
   - выявление аномалий (например, `Power = 0`, `RegistrationYear = 2060`),
   - анализ неинформативных признаков.
3. **Предобработка**:
   - заполнение или удаление пропусков,
   - удаление аномальных значений,
   - кодирование категориальных признаков (One-Hot / Ordinal Encoding),
   - масштабирование (для линейных моделей).
4. **Подготовка выборок**: train / valid / test.
5. **Обучение моделей**:
   - **LightGBM** (градиентный бустинг) — обязательна;
   - минимум одна **не бустинг** модель (например, Linear Regression, Decision Tree, Random Forest).
   - подбор гиперпараметров для каждой модели.
6. **Сравнение моделей** по трём критериям: RMSE, время обучения, время предсказания.
7. **Выбор финальной модели** и проверка её на тестовой выборке.
