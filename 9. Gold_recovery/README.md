# Проект: Прогнозирование коэффициента восстановления золота из руды

## Описание проекта
Компания «Цифра» разрабатывает решения для промышленных предприятий. Цель проекта — построить прототип модели машинного обучения, которая предсказывает коэффициент восстановления золота из золотосодержащей руды. Модель поможет оптимизировать производство и избежать убыточных режимов работы.

## Данные
Данные представлены тремя файлами:
- `gold_recovery_train_new.csv` — обучающая выборка;
- `gold_recovery_test_new.csv` — тестовая выборка;
- `gold_recovery_full_new.csv` — исходные данные (содержат все признаки).

Признаки описывают параметры добычи и очистки руды на различных этапах: флотация, первичная и вторичная очистка. Целевые признаки: `rougher.output.recovery` (эффективность обогащения на этапе флотации) и `final.output.recovery` (итоговая эффективность).

## Этапы работы
1. **Подготовка данных**
   - Загрузка и изучение данных.
   - Проверка корректности расчёта эффективности обогащения (MAE между расчётным и заданным значением `rougher.output.recovery`).
   - Анализ признаков, отсутствующих в тестовой выборке (они недоступны на момент прогноза).
   - Предобработка: заполнение пропусков, удаление аномалий (нулевые суммарные концентрации), добавление целевых признаков в тестовую выборку.

2. **Исследовательский анализ данных**
   - Анализ изменения концентрации металлов (Au, Ag, Pb) на разных этапах очистки.
   - Сравнение распределений размеров гранул сырья на обучающей и тестовой выборках.
   - Исследование суммарной концентрации всех веществ на разных стадиях.

3. **Построение модели**
   - Реализация функции расчёта итоговой метрики sMAPE.
   - Обучение и оценка моделей (LinearRegression, DecisionTreeRegressor, RandomForestRegressor, DummyRegressor) с помощью кросс-валидации.
   - Выбор лучшей модели и проверка её на тестовой выборке.
